# India EXIM Bank Exam Notes — Operating Systems Master Portal

A fast, responsive, eye-smoothing study portal and application designed for B.Tech. CSE graduates appearing for the **Export-Import Bank of India (India EXIM Bank)** examination.

## 🌟 Quick Start
- **Open in Browser:** Simply double-click `index.html` to open the notes application in Chrome, Edge, or Firefox.
- **Run as Local Web Server:**
  ```powershell
  python -m http.server 8080
  ```
  Then open `http://localhost:8080` in your browser.

## 📚 What's Inside
1. **Complete 8 Banking-Focused Units (100% Syllabus Coverage):**
   - Unit 1: OS Architecture, Kernel Modes & Enterprise Banking OS Stacks (RHEL, AIX, IBM z/OS)
   - Unit 2: Process Management, Threads & IPC (SBI YONO threads, HDFC IBM MQ)
   - Unit 3: CPU Scheduling in High-Concurrency Banking Servers (Convoy Effect, Round Robin, CFS, Aging)
   - Unit 4: Process Synchronization, Concurrency & Deadlocks (Axis Bank concurrent debit, Banker's Algorithm, Lock Ordering)
   - Unit 5: Memory Management & Virtual Memory (Paging, TLB, Linux HugePages 2MB, Thrashing at SBI, OOM Killer)
   - Unit 6: Storage, File Systems, Disk Scheduling & I/O (ext4/XFS Journaling, LVM at ICICI Bank, RAID 10 vs RAID 6, DMA)
   - Unit 7: Virtualization, Containers & High-Availability OS Clustering (Type-1 Hypervisors vs OpenShift Containers, STONITH Fencing)
   - Unit 8: Linux/Unix Administration, OS Hardening & RBI Compliance (8 Essential Linux Diagnostic Commands, RBI IT Governance 4 Pillars)
2. **Practical Exam Question Bank (100% Bank-Only Examples):**
   - **Section A:** Part I Case Studies (2 × 40 Marks | 45 Mins each: India EXIM Bank Core Modernization & Peak Settlement Day Crisis at SBI/HDFC Bank)
   - **Section B:** Part II Descriptive Questions (Q1 to Q14 with full model answers, formulas, and diagrams)
   - **Section C:** Part III Rapid-Fire Banking Interview Scenarios (Questions 1 to 6)
3. **Interactive Tools:**
   - ⚡ **High-Yield Exam Mode** for rapid revision of formulas and key banking points
   - 🔍 **Real-Time Keyword Search** across all units
   - 📊 **Syllabus Progress Tracker** with persistent localStorage saving
   - 🖼️ **Diagram Zoom Viewer** for all architecture schematics
   - 📋 **One-Click Code Copy** for Linux troubleshooting commands
   - 🖨️ **Print / Save as PDF** stylesheet for offline revision
